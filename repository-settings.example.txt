POWER PLATFORM WORKFLOW REPOSITORY SETTINGS v12
================================================

SHARED REUSABLE WORKFLOW REPOSITORY
-----------------------------------

Repository: KayodeAjayi-Veldarr/power-platform-workflows
Workflow ref: main

The shared repository contains the reusable workflow logic and the project
workflow template. The project-specific values are written into each project's
caller workflow files by Install-ProjectWorkflows.ps1.

PROJECT DETAILS FORMAT
----------------------

Project key: <short project identifier>
Solution: <logical name of the solution>
Solution project folder: <folder containing the solution project>
Solution source folder: <folder containing the unpacked solution files>
Default developer alias: <short developer identifier>
Default developer UPN: <developer Microsoft 365 email address>

No project-level GitHub Actions variables are required for these values.

REQUIRED SECRET NAMES
---------------------

PP_TENANT_ID
PP_APP_ID
PP_CLIENT_SECRET

These can be organisation secrets. Give each project repository access through
the organisation secret repository access policy.
