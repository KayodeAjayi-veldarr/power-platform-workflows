AZURE BOARDS AND GITHUB INTEGRATION

Azure DevOps organisation: VeldarrProjects
Azure DevOps project: Chess Playing Agent
Project URL: https://dev.azure.com/VeldarrProjects/Chess%20Playing%20Agent

ONE-TIME CONNECTION

1. Open the Chess Playing Agent project in Azure DevOps.
2. Open Project settings.
3. Under Boards, open GitHub connections.
4. Select Connect your GitHub account or add a GitHub connection.
5. Authorise or configure the Azure Boards GitHub app for the GitHub organisation.
6. Select the GitHub repository used for the Chess Playing Agent project.
7. Complete the connection and confirm the repository appears in GitHub connections.
8. Do not connect the same GitHub repository to a second Azure DevOps organisation or project.

WORKFLOW USE

Run Commit Feature Changes and populate Azure work item IDs.

Accepted examples:
123
123,456
AB#123 AB#456

The workflow converts these to AB# references and adds them to:
- the Git commit message
- the pull request description, when a pull request is created

Link only:
Update chess move validation AB#123

Link and move the item toward completion only when intended:
Fixed AB#123

VERIFICATION

1. Push the commit.
2. Open work item 123 in Azure Boards.
3. Confirm the GitHub commit appears in the Development section.
4. If a pull request was created, confirm it also appears in the Development section.
